Http.client

作者: long | 2025-03-16

http.client是Python标准库中的模块，提供了底层的HTTP客户端功能。虽然功能强大，但API较为复杂，适合需要更精细控制的场景。

示例：

import http.client

conn = http.client.HTTPSConnection("api.example.com")
conn.request("GET", "/data")
response = conn.getresponse()
print(response.status, response.reason)  # 状态码和原因
data = response.read()
print(data.decode('utf-8'))  # 响应内容
conn.close()
